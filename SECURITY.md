# Security policy

## Supported versions

Only the latest release - the version the live site runs - receives fixes. Older tags stay as they are.

## Reporting a problem

Please report a vulnerability privately, not in a public issue:

1. Open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](../../security/advisories/new)).
2. Describe the problem, the address or file it affects, and how to reproduce it.

You will get an answer within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer to stay anonymous.

The site is static: it has no accounts, forms, cookies or database, and it stores only the theme and animation choices in your own browser. A report about the response headers, the content security policy or the dependencies is just as welcome.
